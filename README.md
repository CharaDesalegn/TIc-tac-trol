# Tic Tac Troll
<img width="1315" height="871" alt="image" src="https://github.com/user-attachments/assets/4d4aae42-0caf-49fc-803c-059269ff9c3f" />


Having a boring day? Play Tic Tac Toe with Tic Tac Troll!

He’s a clever opponent—but not an AI. The game features an interactive face and dialogue that changes based on the game situation.

Tic Tac Troll starts off a bit silly but gradually gets harder—this was done on purpose to keep things fun and challenging.

Your scores are saved between you and Tic Tac Troll.

No AI is used to generate moves; it’s all programmed logic.

Created on August, 2024.

Open `index.html` to play!
